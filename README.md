# AGI + WorkBuddy 分享会 · 签到

纯前端签到应用，数据只存在本机浏览器，断网也能用，不需要服务器。

**Windows 电脑 + iPad 现场部署，从安装到演练的步骤见 [WINDOWS.md](WINDOWS.md)。**

## 使用

1. 在签到设备上用 Chrome 或 Safari 打开 `index.html`。推荐的做法是在项目目录执行 `python3 server.py`（Windows 双击 `start-windows.bat`），然后访问 `http://<电脑IP>:8000`。
2. 打开 `admin.html`（默认 PIN 是 `0000`），导入名单、上传 logo、修改 PIN。默认 logo 是 `assets/logo.png`（AGITopia，透明底），后台上传的 logo 会覆盖它，点「恢复默认 logo」可切回。
3. 来宾的签到流程：输入首字母 → 点一次自己的名字 → 长按名字 1 秒。按住时 logo 由暗变亮，松手会回退。
4. 工作人员在签到页**左上角连续点 5 次**，输入 PIN 后进入管理页。

## 星空大屏（可选）

大屏显示活动 logo、主题文字和一片星空。开场时点亮底部一小块，之后每有一人签到就多亮几颗星，新点亮的星会闪一下。大屏不显示人数和名字，也没有「全部到齐」的效果。签到人数换算成星星时，按名单人数平均分配：到场 50 人时大约亮一半，至少每签到一人亮一颗。

部署方式：Windows 电脑接大屏并运行服务，iPad 或安卓平板通过同一个 WiFi 签到。

1. Windows 电脑安装 Python 3（python.org 下载，安装时勾选 **Add python.exe to PATH**）。
2. 把项目文件夹拷到 Windows 电脑，双击 `start-windows.bat`。第一次运行时，Windows 防火墙弹窗要选**允许**。如果 iPad 打不开，到「设置 → 网络和 Internet → WLAN → 当前网络属性」把网络类型改成**专用网络**。
3. 黑色窗口里会打印签到页地址，例如 `http://192.168.1.20:8000/index.html`，电脑有多个网卡时会列出备选地址。这个窗口在活动期间不要关。
4. iPad 用 Safari 打开签到页地址，再打开同一地址下的 `admin.html` 导入名单。不同地址打开的页面数据是分开的，所以名单要在这个地址下导入。管理页顶部显示「大屏已连接」就说明联动正常。
5. 电脑浏览器会自动打开 `http://localhost:8000/screen.html`。把这个窗口拖到投影屏上，点一下画面进入全屏。

更新了项目文件后，重启 `start-windows.bat`，再在 iPad 上刷新签到页即可生效（服务会让浏览器每次都检查文件有没有更新）。如果是「添加到主屏幕」打开的，要从多任务界面划掉再重新打开。

签到不依赖大屏：平板每次签到后，以及之后每 5 秒，都会把「已签到人数 / 名单人数」发给电脑，发送失败就忽略，下次再发。服务停了、WiFi 断了，签到照常进行，恢复后大屏自动补亮。大屏连不上服务或 30 秒没收到数据时，右下角会出现一个红色小点，已经亮的星不会熄灭。多台平板同时签到时，大屏把各台的签到数相加；同一位来宾不要在两台平板上都签。

### 活动前演练

1. 电脑双击 `start-windows.bat`，iPad 打开签到页并导入名单，管理页显示「大屏已连接」。
2. 签两个人，看大屏星星变多。
3. 关掉电脑上的黑色窗口，再签一个人，iPad 照常签到成功，管理页变成「大屏未连接」。
4. 重新双击 `start-windows.bat`，几秒后大屏补亮，管理页恢复「大屏已连接」。
5. 演练完在管理页「清空所有签到记录」。

现场 WiFi 如果开了「客户端隔离」（常见于访客网络），iPad 连不上电脑。不确定时用手机开热点，电脑和 iPad 都连这个热点。

## 导出单文件 Demo

管理页「数据与备份」里点「导出单文件 Demo（HTML）」，会下载一个 `签到Demo_xxx.html`：

- 当前名单、logo、活动名称都打包在文件里，双击就能打开，不需要服务器或网络。
- 签到页和管理页在同一个文件里，左上角点 5 次输入 PIN 进入管理页。
- 默认勾选「不带签到记录」，别人打开时是全新的签到状态。
- 每个人打开后的签到数据存在各自浏览器里，互不影响。管理页有「重置为初始名单」按钮。
- PIN 和名单都在文件里，不要把真实名单的 Demo 发到公开渠道。

导出时管理页必须通过 http 打开（`python3 server.py`），直接双击 `admin.html` 读不到源文件。

## 名单格式

每行一人，列依次为 `姓名, 公司, 别名`，第一行可以是表头。也可以直接从 Excel 复制粘贴（Tab 分隔）。
多音字姓氏（曾、单、解、仇、区）的两种读音都能搜到。如果某人有特殊读音或英文名，在「别名」列补上即可。

## 容错设计

| 现场情况 | 处理方式 |
|---|---|
| 搜不到人 | 首字母、全拼、首字母和全拼混输、中文、别名都能搜。找不到时提示联系工作人员，由工作人员在管理页「现场添加」，可以勾选直接签到 |
| 重名 | 结果卡片显示公司；同名同公司的来宾不能重复导入 |
| 重复签到 | 已签到的人会标出签到时间，点了也不进入长按页 |
| 签错人 | 管理页「撤销签到」 |
| 来宾不会长按 | 管理页「代签到」 |
| 走开没操作 | 确认页停留 30 秒、搜索框 60 秒无操作会自动复位 |
| 数据损坏 | 每分钟保存一份自动快照（保留 5 份），启动时自动恢复并提示；也可以手动下载或恢复完整备份 |
| 误操作清空 | 清空签到记录或删除全部名单前，要手动输入确认词，并且会先自动下载一份备份 |
| 多标签页 | 签到页和管理页在同一设备上实时同步 |

## 活动前检查清单

- [ ] **不要用无痕模式**，无痕模式下数据可能保存不下来。
- [ ] iPad：Safari 打开后用「添加到主屏幕」全屏运行，再开启「引导式访问」，防止来宾退出页面。
- [ ] 把自动锁屏设为「永不」，并接上电源。
- [ ] 导入名单后，在管理页的「拼音（核对）」列检查多音字。
- [ ] 改掉默认 PIN。
- [ ] 开场前、中场各点一次「下载完整备份」。
- [ ] 准备一份纸质名单，以防设备故障。
